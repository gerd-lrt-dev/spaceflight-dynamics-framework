# VER-ROT-002 — Torque-Free Gyroscopic Rotation

## Objective

Verify the nonlinear gyroscopic coupling of the SDF rigid-body rotational dynamics model for torque-free multi-axis rotation of an asymmetric rigid body.

The verification shall exercise

\[
\dot{\boldsymbol{\omega}}
=
\mathbf{I}^{-1}
\left[
\boldsymbol{\tau}
-
\boldsymbol{\omega}\times
(\mathbf{I}\boldsymbol{\omega})
\right]
\]

with

\[
\boldsymbol{\tau}=0
\]

and a diagonal but asymmetric inertia tensor.

---

# Verification Data Policy

The numerical reference values below were generated independently of SDF using
SciPy `solve_ivp(method="DOP853", rtol=2.3e-14, atol=2e-14)` on the Euler
rigid-body differential equations. Reported digits are rounded and are not
intended to imply equal precision of the SDF integrator.

**Integrator assumptions:** Numeric acceptance thresholds for propagation assume
explicit (forward) Euler time stepping for angular velocity,
`omega_next = omega + dt * angularAcceleration(omega)`. For other SDF
integration paths (semi-implicit Euler, RK4, etc.), retain the independent
reference values but requalify the integrator-dependent thresholds.

**Numerical comparison rules:** Quantities stated as `max` are checked across
**all steps, including step zero**. Unless otherwise specified, a strict `<`
comparison is used. Invalid (`NaN`/`Inf`) values fail. No test shall use a
reference generated by the SDF production integrator itself.

# Test Case 1 — Initial Gyroscopic Angular Acceleration

Suggested GoogleTest name:

```text
VER_ROT_002_GyroscopicDerivative.MatchesAnalyticalSolution
```

## Purpose

Verify the nonlinear gyroscopic coupling term directly at the initial state.

No propagation is performed.

## Input

```text
I     = diag(100, 200, 300) kg m²
omega = (0.1, 0.2, 0.3) rad/s
tau   = (0, 0, 0) N m
```

## Analytical reference

Euler's torque-free rigid-body equations:

\[
I_x\dot{\omega}_x
=
(I_y-I_z)\omega_y\omega_z
\]

\[
I_y\dot{\omega}_y
=
(I_z-I_x)\omega_z\omega_x
\]

\[
I_z\dot{\omega}_z
=
(I_x-I_y)\omega_x\omega_y
\]

Therefore:

\[
\dot{\omega}_x
=
\frac{200-300}{100}(0.2)(0.3)
=
-0.06
\]

\[
\dot{\omega}_y
=
\frac{300-100}{200}(0.3)(0.1)
=
+0.03
\]

\[
\dot{\omega}_z
=
\frac{100-200}{300}(0.1)(0.2)
=
-0.006666666666666667
\]

Expected result:

```text
angularAcceleration =
(
    -0.06,
     0.03,
    -0.006666666666666667
) rad/s²
```

## Acceptance criteria

- X component matches analytical reference.
- Y component matches analytical reference.
- Z component matches analytical reference.
- All signs match the analytical Euler equations.
- Use the production `RigidBodyRotationalModel`.
- No propagation is required.

Suggested tolerance:

```text
1e-12 rad/s²
```

---

## Fixed verification dataset and pass/fail rule (Test 1)

| Field | Value |
|---|---|
| Initial `I` | `diag(100, 200, 300)` kg m² |
| Initial `omega` | `(0.1, 0.2, 0.3)` rad/s |
| Input `tau` | `(0, 0, 0)` N m |
| Propagation | None (`t = 0 s`) |
| Expected `omegaDot` | `(-0.0600000000000000, +0.0300000000000000, -0.006666666666666667)` rad/s² |
| Absolute component tolerance | `< 1e-12` rad/s² |

**PASS:** `abs(omegaDot_actual[i] - omegaDot_expected[i]) < 1e-12`
for each of x, y and z. Also assert finite outputs. This directly covers T19 / VER-ROT-002A.

# Test Case 2 — Torque-Free Angular Velocity Evolution

Suggested GoogleTest name:

```text
VER_ROT_002_AngularVelocity.MatchesIndependentReference
```

## Purpose

Verify that the multi-axis angular velocity evolves correctly under nonlinear gyroscopic coupling.

Unlike Test Case 1, the angular velocity must be updated after every simulation step.

## Input

Use the common reference configuration.

Suggested propagation:

```text
dt       = 0.01 s
duration = 1.0 s
steps    = 100
```

## Required simulation loop

For every step:

```text
1. Compute angular acceleration from current omega.
2. Propagate angular velocity with the production integration path.
3. Use the updated omega in the next step.
```

Conceptually:

\[
\dot{\omega}_k
=
f(\omega_k)
\]

\[
\omega_{k+1}
=
\mathrm{Integrate}
(
\omega_k,
\dot{\omega}_k,
\Delta t
)
\]

## Reference

The final

\[
\omega(1\,s)
\]

shall be compared against an independently generated high-accuracy numerical reference.

The reference must not use the same SDF integration implementation.

Recommended reference generation:

```text
High-accuracy RK4 or scipy.solve_ivp
with a much smaller internal timestep / tight tolerances.
```

## Acceptance criteria

- All three angular-velocity components evolve.
- Final `omega` matches the independent reference within a justified tolerance.
- No external torque is applied.
- The result must demonstrate genuine multi-axis coupling.

---

## Fixed verification dataset and pass/fail rule (Test 2)

| Field | Value |
|---|---|
| Initial state | Common configuration (`I`, `omega0`, `tau=0`, `q0`) |
| Integration | Forward Euler (`dt=0.01 s`, `N=100`, `t_end=1 s`) |
| Independent reference `omega(1 s)` | `(0.0370354933652774, 0.2205184169886715, 0.2951675387351000)` rad/s |
| Acceptance tolerance | `norm(omega_actual - omega_reference) < 2e-4` rad/s |
| Auxiliary (not an independent oracle) | Forward Euler is expected to give approximately `(0.03704886, 0.22061638, 0.29514613)` rad/s |

**PASS:** The three components are finite, the norm error is strictly below
`2e-4 rad/s`, and the external torque is identically zero throughout.
Do not assert that all components are monotonic; the dynamics are coupled.

# Test Case 3 — Rotational Kinetic Energy Conservation

Suggested GoogleTest name:

```text
VER_ROT_002_Conservation.RotationalEnergyRemainsBounded
```

## Purpose

Verify that torque-free rotational motion approximately conserves rotational kinetic energy.

For an ideal rigid body with no external torque:

\[
E_{rot}
=
\frac12
\boldsymbol{\omega}^{T}
\mathbf{I}
\boldsymbol{\omega}
\]

should remain constant.

## Initial analytical reference

\[
E_0
=
\frac12
\left(
100(0.1)^2
+
200(0.2)^2
+
300(0.3)^2
\right)
\]

\[
E_0
=
18\;\mathrm{J}
\]

Expected initial value:

```text
E0 = 18.0 J
```

## Propagation

Suggested:

```text
dt       = 0.01 s
duration = 10.0 s
steps    = 1000
```

At every step compute:

\[
E_k
=
\frac12
\omega_k^T I \omega_k
\]

Track at least:

```text
initial energy
final energy
maximum deviation from initial energy
```

## Acceptance criterion

The individual components of `omega` may change.

The rotational kinetic energy should remain close to

```text
18.0 J
```

within a justified numerical tolerance.

Recommended metric:

\[
\epsilon_E
=
\frac{|E(t)-E_0|}{E_0}
\]

The final tolerance should be selected based on the actual numerical integration method and documented explicitly.

---

## Fixed verification dataset and pass/fail rule (Test 3)

| Field | Value |
|---|---|
| Initial state | Common configuration |
| Integration | Forward Euler, `dt=0.01 s`, `N=1000` |
| Analytical reference | `E0 = 18.000000000000 J` |
| Independent exact-physics expectation | `E(t)=18 J` for any `t` |
| Relative maximum deviation bound | `max_k abs(E_k-18)/18 < 3e-3` |
| Equivalent absolute bound | `max_k abs(E_k-18) < 0.054 J` |
| Forward Euler indicative final value (10 s) | `E(10 s) ≈ 18.03669404768 J` |
| Forward Euler indicative max relative deviation | `≈ 2.03856e-3` |

**PASS:** At every step `E_k` is finite and the maximum relative deviation is
strictly below `3e-3`. Do not compare a forward-Euler result with 18 J using
machine-precision tolerance: that would incorrectly test the integrator rather
than the rigid-body physics.

# Test Case 4 — Angular Momentum Magnitude Conservation

Suggested GoogleTest name:

```text
VER_ROT_002_Conservation.AngularMomentumMagnitudeRemainsBounded
```

## Purpose

Verify conservation of total angular-momentum magnitude during torque-free rotation.

Body-frame angular momentum is:

\[
\mathbf{L}_B
=
\mathbf{I}\boldsymbol{\omega}
\]

Initial value:

\[
\mathbf{L}_{B,0}
=
\begin{bmatrix}
100(0.1)\\
200(0.2)\\
300(0.3)
\end{bmatrix}
=
\begin{bmatrix}
10\\
40\\
90
\end{bmatrix}
\]

The individual body-frame components are **not expected to remain constant**.

The conserved quantity is the magnitude:

\[
|\mathbf L|
=
\sqrt{
L_x^2+
L_y^2+
L_z^2
}
\]

Initial reference:

\[
|\mathbf L_0|
=
\sqrt{
10^2+
40^2+
90^2
}
\]

\[
|\mathbf L_0|
=
\sqrt{9800}
\approx
98.9949493661
\]

Expected initial value:

```text
|L0| ≈ 98.9949493661 kg m²/s
```

## Propagation

Use the same propagated states as Test Case 3.

At each step:

```text
L = I * omega
L_norm = L.norm()
```

## Acceptance criterion

The components

```text
Lx
Ly
Lz
```

may change with time.

The magnitude

```text
|L|
```

shall remain approximately constant.

Recommended metric:

\[
\epsilon_L
=
\frac{
\left|
|\mathbf L(t)|-|\mathbf L_0|
\right|
}{
|\mathbf L_0|
}
\]

Tolerance must be justified based on numerical integration error.

---

## Fixed verification dataset and pass/fail rule (Test 4)

| Field | Value |
|---|---|
| Initial state | Common configuration |
| Integration | Forward Euler, `dt=0.01 s`, `N=1000` |
| Expected initial `L_body` | `(10, 40, 90)` kg m²/s |
| Expected invariant magnitude | `sqrt(9800) = 98.99494936611666` kg m²/s |
| Relative maximum deviation bound | `max_k abs(norm(L_k)-sqrt(9800))/sqrt(9800) < 1e-3` |
| Equivalent absolute bound | `max_k abs(norm(L_k)-sqrt(9800)) < 0.0989949494` kg m²/s |
| Forward Euler indicative final magnitude (10 s) | `≈ 99.05796462581` kg m²/s |
| Forward Euler indicative max relative deviation | `≈ 6.36550e-4` |

**PASS:** The body-frame momentum vector and norm are finite at every step,
and the maximum relative norm deviation stays strictly below `1e-3`.
The vector components are not individually conserved in the body frame.

# Test Case 5 — Quaternion Normalization During Gyroscopic Rotation

Suggested GoogleTest name:

```text
VER_ROT_002_Attitude.QuaternionRemainsNormalized
```

## Purpose

Verify that attitude propagation remains numerically valid during coupled multi-axis rotation.

## Initial condition

```text
q0 = (1, 0, 0, 0)
```

## Propagation

Use:

```text
dt       = 0.01 s
duration = 10.0 s
steps    = 1000
```

For each step:

```text
1. Compute angular acceleration.
2. Propagate angular velocity.
3. Propagate attitude using the production quaternion path.
```

## Acceptance criterion

For every propagated state:

\[
\|q\|
\approx
1
\]

Track either:

```text
maximum quaternion norm deviation
```

or verify the norm directly after every step.

Suggested criterion:

\[
|\|q\|-1|
<
\epsilon_q
\]

If the production code explicitly renormalizes the quaternion, a tight tolerance such as

```text
1e-12
```

may be appropriate.

---

## Fixed verification dataset and pass/fail rule (Test 5)

| Field | Value |
|---|---|
| Initial `q0` | `(w=1, x=0, y=0, z=0)` |
| Initial `omega0` | `(0.1, 0.2, 0.3)` rad/s |
| External torque | `(0, 0, 0)` N m |
| Integration | Production attitude path, `dt=0.01 s`, `N=1000` |
| Expected quaternion norm | `norm(q_k)=1` for all `k` |
| Acceptance if explicit per-step quaternion renormalization exists | `max_k abs(norm(q_k)-1) < 1e-12` |

**PASS (renormalizing production implementation):** Each quaternion is finite,
and its norm deviates by less than `1e-12` at every step.

**Implementation-dependent qualification:** This norm test alone does not
verify the quaternion attitude or sign convention. If SDF's production
attitude propagation does **not** explicitly normalize `q`, the `1e-12` bound
is **not** a valid acceptance threshold for first-order quaternion Euler
integration. In that case, document the exact attitude update and establish a
separate method-specific numerical tolerance before marking this test passed.
Do not silently increase the threshold to make it pass.

# Test Case 6 — Timestep Convergence

Suggested GoogleTest name:

```text
VER_ROT_002_Convergence.SmallerTimestepReducesError
```

## Purpose

Verify that the numerical solution converges as the timestep is reduced.

## Configuration

Propagate the same initial state to:

```text
t = 1.0 s
```

using three timestep sizes:

```text
dt = 0.020 s →  50 steps
dt = 0.010 s → 100 steps
dt = 0.005 s → 200 steps
```

Use the same independent high-accuracy reference as Test Case 2.

## Error definition

For example:

\[
e_{\omega}
=
\|
\omega_{SDF}(t)
-
\omega_{ref}(t)
\|
\]

Calculate:

```text
error_dt_0020
error_dt_0010
error_dt_0005
```

## Acceptance criterion

The error should decrease as the timestep is reduced:

\[
e_{0.005}
<
e_{0.010}
<
e_{0.020}
\]

The exact convergence ratio does not need to be prescribed unless the numerical integration order is explicitly part of the test.

---

## Fixed verification dataset and pass/fail rule (Test 6)

| Field | Value |
|---|---|
| Initial state | Common configuration |
| Terminal time | `1.0 s` |
| Steps | `dt=0.020: N=50`, `dt=0.010: N=100`, `dt=0.005: N=200` |
| Independent `omega_ref(1 s)` | `(0.0370354933652774, 0.2205184169886715, 0.2951675387351000)` rad/s |
| Expected forward-Euler error at `dt=0.020` | `e_0.020 ≈ 2.02362566e-4` rad/s |
| Expected forward-Euler error at `dt=0.010` | `e_0.010 ≈ 1.01160320e-4` rad/s |
| Expected forward-Euler error at `dt=0.005` | `e_0.005 ≈ 5.05748381e-5` rad/s |

**PASS (forward Euler):** All errors are finite and satisfy
`0 < e_0.005 < e_0.010 < e_0.020`.
Additionally, for forward Euler only, use the broad expected first-order band
`0.40 < e_0.010/e_0.020 < 0.60` and
`0.40 < e_0.005/e_0.010 < 0.60`.

**Note:** If a higher-order integrator is selected, the decreasing-error
criterion remains relevant but the `0.40...0.60` ratios do not apply. Near
machine precision, strict ordering can also become unreliable.
